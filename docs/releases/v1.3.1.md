# v1.3.1 · 完整照片与口味选择

- 酒单列表、详情和编辑预览默认完整显示上传照片；已有照片无需重新上传，手动应用裁剪后才显示局部。
- 可在「完整显示 / 裁剪封面」之间切换，裁剪不修改照片文件。
- 口味提供清爽、酸甜、微甜、微苦、果香、柑橘、花香、茶香、草本、醇厚、辛香、气泡，可多选与取消；已有自定义口味保留。
- 移除酒单底部存储提示和上传区域重复说明，保留必要的进度、错误、草稿反馈。
- 安装包按「安装包 / 版本 / Android 或 iOS」归档，包含版本说明、文件校验和索引。

## 安装与迁移

Android 测试版显示为「心晴 1.3.1」，包名 com.xiaojunmaoi.xinqing.album.v131，与旧版并存。先在旧版分别导出图文日记和酒单备份，再导入新版；不要卸载有未转移记录的旧版。iOS 提供未签名 IPA，需苹果签名后安装。
