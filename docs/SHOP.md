# v1.3 · 解忧杂货店与图片处理
日期：2026-09-30。与主 PRD、照片手帐 PRD 共同构成当前功能说明。

## 信息架构
主导航：今日心情 / 情绪回顾 / 解忧杂货店。
解忧杂货店只有两个子栏，顺序固定：
1. 自我关怀：完整保留原来的呼吸练习、四种白噪音、散步建议和关怀记录，不拆分。
2. 骏马特调：个人配方与喜欢的酒款/饮品收藏。也可记录无酒精饮品。

进入原 #care 地址仍可打开自我关怀；主页关怀便签仍调用原活动，不按低落情绪推荐饮酒。

## 酒单浏览和阅读
- 浏览、详情、添加/编辑独立，上传控件不放进列表。
- 「全部 / 可以自己调 / 好喝推荐」按内容类型筛选。
- 卡片显示封面、名称、口味、已填写的酒精情况、查看配方/推荐按钮。
- 电脑三列，窄屏两列，手机单列；封面统一 4:3，不按源照片尺寸撑开布局。
- 点击查看完整照片；详情按照类型呈现材料步骤或推荐理由。返回酒单恢复原筛选和滚动位置。
- 新设备默认空酒单；可选择「看看示例酒单」。示例与个人集合隔离，不把虚构内容写进个人存储。

## 收录与编辑
- 名称必填（60字）；类型二选一；口味、材料、步骤、心得或推荐理由选填。
- 可上传 JPG / PNG / WebP；HEIC / HEIF 取决于当前设备解码能力。单张不超过20MB、5000万像素。
- 照片由统一图片处理模块在本机处理；没有上传到服务器。
- 可更换照片、使用默认插画、从系统拍照入口选择图片。
- 裁剪窗口提供拖动、方向键、缩放和水平/垂直滑块；取消不改变封面，确认后保存裁剪参数。
- 裁剪不改写已处理的照片字节；列表按参数显示，完整照片预览仍能看到全图。手机相册原图不受影响。
- 草稿自动保存，返回和刷新可恢复。处理或保存中阻止离开；保存失败保留输入。
- 已保存酒单可编辑或确认删除；删改不影响其他酒单或日记。

## 本机存储与备份
本轮沿用已有离线、本机存储方式；没有账号或公开内容管理后台，上传图片不会自动向访问者公开。
酒单使用独立 IndexedDB 数据库 xinqing-drinks；不改变日记库结构。
酒单备份包含已保存条目的文字、照片字节与裁剪参数；不包含草稿。与图文日记分别备份。
导入先校验格式并预览新增/重复数，确认后事务写入；已有ID跳过，不覆盖本机数据。
备份上限100MB；文件为明文。网页使用下载，App使用已有系统分享插件。两端不自动同步，用户可手动导出后导入。
独立示例模式下的增改保存在本次内存中，退出示例即回到个人酒单，未写入个人数据库。

## 日记多图处理修复
原流程逐张解码压缩，整批结束才显示缩略图，并逐张触发草稿保存。
现流程：
- 有界并行：最多两个后台任务；低内存设备使用一个，避免同时解码九张大图。
- 支持时使用 Web Worker + OffscreenCanvas；不可用时自动回退到主页面处理，并让出事件循环。
- 每张完成即显示，最终保留文件选择顺序；过程中仍可继续写正文。
- 20MB/5000万像素限制保持，最长边1800px。小尺寸且确认没有EXIF/XMP/IPTC/文本元数据的图片直接复用，减少反复编码；有元数据的图片重新编码。
- 一批图片完成后合并保存草稿，包含处理过程中输入的文字。
- 可停止添加，保留已经处理好的图片；单张失败不丢弃其他成功照片。
- 正在处理与未保存草稿有离开提示，停止后可继续添加。

## 验证
- 16项单元测试；酒单真实浏览器流程覆盖上传、裁剪、刷新草稿、类型切换、筛选、详情、删除、备份恢复和示例隔离。
- 七种宽度（320/390/640/768/1024/1440/1920）验证酒单与编辑器无横向溢出，手机裁剪弹窗可操作。
- 9张1200万像素测试图片：旧串行流程1144ms，新流程802ms；首张预览212ms；处理期间输入可用，草稿最终仅写入一次。
- 耗时是同一桌面 Chromium 会话的一次本地样本，不代表所有手机或图片都提速30%。仍需真机测试相机、相册权限、系统分享、后台回收等平台行为。
