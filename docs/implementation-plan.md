# 心晴手帐原型

依据：用户已选择第 3 张暖色手帐效果图，并要求制作可交互 HTML。

## 交付

使用独立 HTML、CSS、原生 JavaScript 与本地图片，不要求安装前端框架。双击 index.html 或通过本地服务访问。延续原 GitHub/Vercel 项目与域名。

## 实现顺序

1. 测试日记校验、七天本地日期聚合、触发因素统计、损坏数据处理和示例隔离。
2. 实现日期侧栏、心情输入、关怀便签、趋势图以及手机布局，匹配第 3 版。
3. 实现 localStorage 日记增删改、示例浏览、趋势与因素分析。
4. 实现呼吸计时、用户主动开启的雨声合成、散步引导及活动后反馈。
5. 浏览器验证完整流程、持久化、示例隔离、移动端布局；保存视觉检查结果。

## 文件职责

- index.html：语义化页面结构、表单、活动对话框。
- styles.css：手帐风格和响应式布局。
- journal.js：可独立测试的日期、记录、统计与推荐逻辑。
- app.js：DOM、浏览器存储、趋势绘制、计时及音频。
- assets/：独立本地图像和开源图标。
- serve.cjs：只提供公开原型文件的本地静态服务器。
- tests/journal.test.cjs：有实际数据输入的核心行为测试。

## 验证重点

空记录不伪造趋势；用户文本通过 textContent 写入；示例记录不写入个人存储；存储失败时不伪称保存成功；活动退出停止计时和音频；本地日期不因 UTC 转换错位。
