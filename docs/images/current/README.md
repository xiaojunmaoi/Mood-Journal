## 采集方式

- 采集日期：2026-10-13。
- 来源：本地运行的项目页面；功能代码对应提交 `b6ea9ac`，本次仅调整文档和截图。
- 数据：通过「查看示例」进入内置示例手帐。日记文字、照片和饮品均为项目已有的虚构演示素材，不包含个人记录。
- 电脑按 1440px 宽度、手机按 390px 宽度检查响应式布局；截图像素尺寸可能因浏览器滚动条和导出方式略有差异。
- 长页面使用完整页面截图；手机日记详情、手机日记编辑和电脑配方详情使用加高视口，以保留完整内容。长图不表示普通手机一屏可见。
- 日期选择、自然声、呼吸与散步展示实际弹窗。自然声和计时练习处于开始前状态。
- 图片为浏览器直接导出的 JPEG，未重绘页面内容；手机截图不等同于 Android 或 iOS 真机验收。
