# 情绪日记与自我关怀

美团 AI Coding 项目实战：帮助用户记录情绪、理解触发因素，并找到适合自己的日常自我关怀方式。

## 当前状态

已完成仓库初始化。应用功能及 Vercel 部署尚未完成。

## 计划功能

- 情绪记录：选择情绪、标记强度、记录事件与感受。
- 情绪回顾：展示情绪变化，整理常见触发因素。
- 自我关怀：根据当前感受推荐冥想、音乐、运动等日常活动。
