# v1.3.2 · 配方摘记卡

- 网页版采用确认的双列摘记卡，手机采用左侧小图、右侧标签与摘记的单列卡片。
- 类别以纸质小标签区分「可以自己调 / 好喝推荐」；点击整张卡片或文字箭头进入详情。
- 照片按原比例缩入小图区域，不强行裁切、不再放进宽大的固定画框；主动选择过的裁剪封面仍保留。
- 摘记来自已保存的配方材料、心得或推荐理由；长标题、标签、摘要有明确排版边界，完整内容仍在详情。
- 安装包目录只保留最新版本，按 Android / iOS 分类，并附 SHA256 和版本来源。新版双端校验通过后再移除旧包。

## 安装与迁移

Android 测试应用为「心晴 1.3.2」，包名 `com.xiaojunmaoi.xinqing.album.v132`，与已装旧版数据独立。先在旧 App 分别导出日记与酒单，再导入新版。清理的是电脑和 GitHub 上的旧安装文件，不会卸载手机应用或删除记录。

iOS 提供同版未签名 IPA，需要苹果签名后安装。
